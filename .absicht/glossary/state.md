definition: >-
  The six-valued incompleteness of an element: `specified`, `constrained`,
  `delegated`, `unknown`, `observed`, `out_of_scope`.
---

Incompleteness is a state, not an omission. Every element declares one, and
each one implies an agent posture; see the README table. `observed` is the
brownfield state: a real system arrives mostly amber, which is an honest
reading and not a failed one.
